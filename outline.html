功能模块设计

🔍 视觉检测引擎

  • YOLOv8 多类别缺陷检测（裂纹/划痕/凹坑/脏污等）
  • 输出：缺陷类型 + bbox 坐标 + 置信度 + 面积占比
  • 支持 ONNX Runtime 加速推理
  • 批量图像处理 + 结果缓存

🧠 LLM 分析层

  • 将检测结果转为结构化文本 prompt
  • 调用大模型生成自然语言描述报告
  • 支持 OpenAI / Claude / 本地模型（Ollama）
  • Prompt 模板可配置（制造业/质检/通用）

📋 报告生成

  • 结构化 JSON → Markdown / HTML / PDF
  • 缺陷数量统计 + 位置标注图
  • 严重程度评级（轻微/中等/严重）
  • 历史报告对比 + 趋势分析

✅ 多模态质检判定

  • 结合检测结果 + 规则引擎 → 合格/不合格
  • LLM 给出判定理由（自然语言解释）
  • 可配置质量标准（数量阈值 / 面积阈值）
  • 批量抽检 + 批次合格率统计

LLM Prompt 工作流（核心亮点）

# 第一步：检测结果 → 结构化 JSON
{
  "image": "product_001.jpg",
  "timestamp": "2026-07-10T10:30:00",
  "detections": [
    {"class": "scratch", "confidence": 0.95, "bbox": [120,85,215,178], "area_pct": 2.3},
    {"class": "scratch", "confidence": 0.88, "bbox": [340,220,550,235], "area_pct": 0.8},
    {"class": "dent",     "confidence": 0.72, "bbox": [400,300,450,355], "area_pct": 1.5}
  ],
  "summary": {"total_defects": 3, "classes": {"scratch": 2, "dent": 1}}
}

# 第二步：结构化数据 → Prompt 模板 → LLM
你是一名工业质检专家。根据以下检测数据，生成一份质检报告。

检测数据：
- 划痕 (scratch)：2 处，面积占比 2.3% / 0.8%
- 凹坑 (dent)：1 处，面积占比 1.5%

请生成：
1. 缺陷描述（自然语言，精确到位置和严重程度）
2. 合格判定（阈值：单缺陷面积 < 3%，总缺陷面积 < 5%）
3. 维修建议

# 第三步：LLM 输出 → 结构化报告 → HTML/PDF

面试叙事逻辑

🎯 痛点

  • 传统质检依赖人工目视，效率低、标准不统一
  • 检测系统只输出 bbox 数字，非技术人员看不懂
  • 报告撰写占质检员 40% 工作时间

💡 方案

  • YOLOv8 做检测 → 输出结构化缺陷数据
  • LLM 做"翻译官"→ 数字转自然语言
  • Prompt 模板 + 规则引擎 → 可配置质检标准

📊 成果

  • 检测速度：< 50ms/张（GPU）
  • 报告生成：< 2 秒（含 LLM 调用）
  • 质检准确率：95%+（与人工对比）
  • 报告可读性：非技术人员可直接理解
